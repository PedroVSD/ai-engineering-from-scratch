# Skill — Avaliação

- Balanceado -> acurácia ok.
- Desbalanceado -> F1 + AUC.
- Custo FN alto (saúde) -> maximize recall.
- Custo FP alto (spam) -> maximize precisão.
- Sempre reporte matriz de confusão.
